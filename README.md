# 🛒 BlinkIT Grocery Sales Analysis & Dashboard

## 📌 Project Overview

Developed an end-to-end BlinkIT grocery sales analysis project combining **Python data analysis** with an **interactive Excel dashboard** to analyze sales performance, outlet efficiency, customer preferences, and product category trends.

The project uses data cleaning, exploratory data analysis, KPI development, visualizations, and interactive dashboarding to turn raw grocery sales data into actionable business insights.

## 🔍 Key Insights

- Medium-sized outlets generated the highest sales.
- Tier 3 locations generated the highest sales among the outlet location tiers.
- Fruits & Vegetables were the highest-selling item category.
- Low Fat products contributed more sales than Regular products.
- Supermarket Type1 generated significantly higher sales than other outlet types.

# 🚀 How to Run the Project

1. Clone the repository.

```bash
git clone https://github.com/hemu0119/Swiggy-Food-Delivery-Analytics.git
```

2. Install required libraries.

```bash
pip install pandas numpy matplotlib seaborn
```

3. Open the Jupyter Notebook.

```bash
jupyter notebook
```

4. Run all cells to reproduce the analysis and visualizations.

🛒 BlinkIT Grocery Sales Analysis Dashboard
Transforming Retail Data into Business Insights with Excel

📌 Project Overview

BlinkIT is India's leading quick-commerce platform, delivering groceries and daily essentials within minutes.

This project focuses on analyzing BlinkIT's grocery sales data using Microsoft Excel to uncover sales trends, customer preferences, outlet performance, and product category insights.

The interactive dashboard enables stakeholders to explore key business metrics through dynamic filters and visualizations, helping drive data-driven decisions in inventory planning, outlet management, and sales optimization.

🎯 Business Problem

BlinkIT generates sales across multiple outlets, product categories, outlet sizes, and customer segments.

The challenge was to create a centralized dashboard that could answer critical business questions such as:

Which outlet types generate the highest revenue?
Which product categories drive maximum sales?
How does outlet location impact performance?
Do customers prefer Low Fat or Regular products?
Which outlet sizes contribute most to overall revenue?
How have outlet establishments performed over time?
